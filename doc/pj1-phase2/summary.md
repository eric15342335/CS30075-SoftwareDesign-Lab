# 第二次作业

本次第二次作业的主题是 插件实践与插件式重构，包含两部分：开发 VSCode 扩展，实现 SVG 文件标记与大纲展示；在 Phase 1 的 CLI 版 SVG 编辑器基础上进行插件式重构，支持图形、命令、树标签和属性行为的扩展，并通过新增插件验证设计。在保持原有功能行为不变的基础上，实践设计模式与开闭原则。

需要提交的内容包括：

    代码仓库
    在 Phase 1 的同一远程仓库中继续开发，提交 VSCode 扩展、重构后的 CLI 及插件源码。提交历史应体现开发过程，最终版本打 tag：p2，已有 tag 不得移动。
    项目文档
    在 doc/README.md 中说明扩展点设计、插件装配方式、重构前后的架构变化与设计决策，并记录与 AI 协作时的检查和修正。
    测试与验证材料
    提交插件与加载器测试、功能兼容性验证、VSCode 扩展运行截图。

具体要求与验收标准见附件。
